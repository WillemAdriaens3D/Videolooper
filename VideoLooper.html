Tap a square to record, tap again to loop it. The first loop sets the length for the rest.

Bars per loop

With the metronome on, the first loop is exactly this many bars and stops by itself. Hands-free loops are this long too. Without the metronome, the first loop counts as this many bars, so the click can follow it later.

Hands-free: record the next loop by itself

When a loop is done, the next empty square waits for you to play, records for the set number of bars and stops by itself. Tap the waiting square or press Space to stop. Use headphones: through the speaker, your loops would start the next recording.

Start recording on the first note

Tap, then play: the loop starts exactly when you start playing. A first loop without the metronome ends on the note you play as you tap stop. Every loop keeps its place against the first loop.

Lower it if soft notes don't start the recording; raise it if noise starts it too early.

Start recording on the beat

When "first note" is off: new loops wait for the next cycle (the next bar with the metronome on). Tapping just after it still catches the start.

Reverb

On everything you hear: loops, the click and Monitor. Loops are recorded dry, so you can change it afterwards.

Input channel

For a 2-input interface like a Scarlett 2i2: pick the input your guitar is plugged into.

Output

Output channels

Latency

Lowest gives the least delay; if you hear crackles, pick Normal. Changing this restarts the app (loops are cleared).

Latency compensation

Measure plays 8 clicks and listens for them. Turn the volume up and hold the mic close to the speaker or headphones. Loops go quiet for 5 seconds.

Camera

Nudge this if the picture runs ahead of or behind the sound.

Keyboard and pedals

Space is the record button: press to start a new loop in the next empty square, press again to stop. It also stops an overdub, or cancels a recording that is still waiting for the first note.
